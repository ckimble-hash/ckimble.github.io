# ckimble.github.io

Self-contained web page served by GitHub Pages and embedded in a HaloPSA dashboard through an iframe.

- Live URL: https://ckimble-hash.github.io/ckimble.github.io/
- `index.html` holds the whole page: HTML, CSS and JavaScript in one file.
- The repo is public, so the page holds no API keys, tokens or client data.

## Current page

Starter page that confirms the setup works. It shows a live clock (JavaScript runs), whether it is displayed inside an iframe, and the viewport size Halo gives it.

## Updating

Commit and push to `main`. GitHub Pages republishes within a minute or two; refresh the Halo dashboard to see the change.
